HIMALAYA DHABA – REAL WEBSITE STARTER

This package contains the customer website, admin dashboard, PWA files, and Supabase database setup.

IMPORTANT:
- This is the complete starter project, but it is NOT live yet.
- Do not put passwords or Supabase service-role keys into these files.
- The live database connection is added after the owner's Supabase project is created.
- The owner/manager should own the hosting/database accounts.

NEXT STEP:
1. Create a Supabase project.
2. Run supabase_schema.sql in Supabase SQL Editor.
3. Put the Supabase URL and anon/publishable key into config.js.
4. Upload the project to hosting such as Cloudflare Pages.
5. Set up the admin user in Supabase Auth.
